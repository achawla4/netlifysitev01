Shannon Source Coding as a Limiting Case of Structured Source Coding

Chawla, Aman

Abstract

Classical source coding theory treats atypical sequences as a monolithic error event and establishes that reliable compression is achievable at rates approaching the entropy of the source. In this note, we develop a structured extension of this framework in which the atypical set is partitioned into clusters, enabling a finer analysis of error events. We show that this structure induces a rate–error tradeoff governed by a parameter controlling the granularity of clustering. Within this framework, classical Shannon source coding emerges as a limiting case corresponding to vanishing clustering complexity. Furthermore, we identify regimes in which increasing rate leads to improved decay of dominant error events, while remaining consistent with classical asymptotic limits. This establishes a broader perspective in which traditional results appear as boundary phenomena of a richer, structure-aware coding paradigm. Introduction Shannon’s source coding theorem establishes that for a discrete memoryless source with entropy H(X), reliable compression is achievable at any rate exceeding H(X), with probability of error bounded above by an arbitrarily small constant ϵ. The standard proof relies on the notion of the typical set, which captures the high-probability portion of the source space. In this framework, sequences outside the typical set are treated uniformly as errors. While this abstraction is powerful and sufficient for establishing asymptotic optimality, it suppresses potential structure within the atypical set. In particular, it does not distinguish between different types or classes of atypical sequences. This note explores the consequences of introducing structure into the atypical set via clustering. By partitioning atypical sequences into multiple classes, we obtain a refined view of error events and uncover a rate–error tradeoff not visible in classical treatments. We show that Shannon’s result arises as a limiting case of this structured framework when the clustering complexity vanishes. Classical Source Coding Framework Let Xn = (X1, . . . , Xn) be an i.i.d. source sequence drawn from a distribution PX with entropy H(X). For ϵ > 0, define the typical set: A(n) ϵ =  xn : −1 n log P(xn) −H(X) ≤ϵ  . The complement B(n) ϵ = (A(n) ϵ )c is the atypical set. 1

The classical result states that for sufficiently large n: Pr(Xn ∈B(n) ϵ ) ≤ϵ. Encoding proceeds by assigning unique indices to sequences in A(n) ϵ , while sequences in B(n) ϵ are mapped to an error symbol. The total code length is approximately n(H(X) + ϵ) bits. Structured Source Coding We now introduce structure into the atypical set. Let B(n) ϵ be partitioned into k disjoint clusters: B(n) ϵ = kG i=1 Ci. Each cluster groups sequences that are close under a suitable metric (e.g., Hamming distance). The encoder now outputs: • an indicator bit for typical vs atypical, • an index for typical sequences, or • a cluster label for atypical sequences. The total encoding length becomes: 1 + n(H(X) + ϵ) + log k. Define: χ = log k n(H(X) + ϵ). Then the effective rate is: R = (1 + χ)(H(X) + ϵ). Dominant Cluster Probability Let Cmax denote the cluster with the largest probability mass: D = Pr(Xn ∈Cmax). A key observation is that clustering induces a refinement of the error bound: D ≤ϵ1+χ. This inequality captures the idea that distributing the atypical set into multiple clusters reduces the probability mass of the largest component. 2

5 Rate–Error Tradeoff From the bound on D, we obtain: D ≈ϵR/(H(X)+ϵ). Taking logarithms: −log D ≈ R H(X) + ϵ(−log ϵ). This defines a rate–error tradeoff curve: R(D) = (H(X) + ϵ)log D log ϵ . Unlike classical typicality, which provides only a fixed upper bound on error, this formulation reveals how error decreases as a function of rate when structure is exploited. Total Error and Cluster Dominance The total error probability is: Pe = k X i=1 Pr(Xn ∈Ci). We always have: D ≤Pe ≤kD. If the largest cluster dominates, i.e., X i̸=max Pr(Xn ∈Ci) = o(D), then: Pe ∼D. In this regime, the rate–error tradeoff extends directly to total error. Exponent Behavior Define: α = −log ϵ H(X) + ϵ. Then: −1 n log D = αR n . For total error: −1 n log Pe ≥(α −1)R + (H(X) + ϵ) n . When α > 1, i.e., −log ϵ > H(X) + ϵ, the exponent exhibits positive dependence on rate. 3

8 Shannon Theory as a Limiting Case Consider the limit: χ →0 ⇐⇒ log k n →0. Then: R →H(X) + ϵ, D →ϵ, Pe →ϵ. Thus, the structured framework reduces to classical typicality-based coding. Interpretation Shannon’s source coding theorem corresponds to the boundary point: χ = 0. For χ > 0, we move into a regime where additional structure is exploited, yielding refined error behavior. Discussion The structured source coding framework reveals that the atypical set possesses internal geometry that can be leveraged to improve performance in certain regimes. Classical theory, while optimal in an asymptotic sense, does not capture this structure. The key insight is that error events are not homogeneous. By partitioning them and analyzing their distribution, one can obtain refined bounds that depend on rate. Importantly, this does not contradict classical results. Instead, it extends them by introducing an additional parameter controlling structure. The classical theory is recovered when this parameter vanishes. Conclusion We have shown that Shannon source coding arises as a limiting case of a more general structured coding framework. By clustering atypical sequences, one obtains a rate–error tradeoff that reveals new regimes of behavior, particularly in finite blocklength settings. This perspective suggests that incorporating structure into coding schemes may yield improved performance in practical scenarios, while remaining consistent with fundamental limits.
