Weak Source Coding: Entropy-Tightened Bounds via Clustering of Atypical Sequences

Chawla, Aman

Abstract

—This paper develops a weak decoding version of Shannon’s source coding theorem. We propose clustering atypical sequences into k classes, thereby refining the traditional error bound. The central result shows that if atypical clusters are small and sparsely placed, the reliability function can be improved. Supplementary analysis using Han’s inequality demonstrates that the largest cluster exhibits entropy collapse, enabling a strictly smaller bound on the probability of the dominant error event. Together, these results suggest that machine learning-inspired clustering can marginally improve the error exponent in source coding. Index Terms—Source coding, weak decoding, atypical se- quences, clustering, entropy bounds, error exponent. I. INTRODUCTION Shannon’s source coding theorem guarantees that the prob- ability of error is bounded above by a small constant ϵ. The error exponent, which captures the rate of decay of error probability with blocklength, is bounded below by −ln ϵ. This paper explores whether clustering atypical sequences can reduce the effective error probability, thereby improving the reliability function. In traditional source coding, atypical sequences are mapped to an arbitrary n(H(X) + ϵ)-bit error declaration. We ask whether unsupervised learning within the atypical set can refine this error declaration. Organization of the Paper: The remainder of this paper is organized as follows. PRIOR WORK The foundations of source coding trace back to Shannon’s seminal theorem, which established that the entropy of a discrete memoryless source provides the fundamental limit on compression [4]. The notion of the typical set, later formalized by Cover and Thomas [3], became central to operationalizing this limit. Typicality ensures that with high probability, source sequences lie in a set of size approximately 2nH(X), thereby enabling efficient encoding. Classical analyses treat all atypical sequences uniformly, declaring an error event without further structural refinement. Subsequent refinements explored the geometry of typical sets and their role in reliability functions. Han’s inequality [5] provided a powerful tool for bounding entropy within subsets, showing that average entropy per element decreases monotonically with subset size. This insight suggests that atyp- ical subsets may exhibit entropy collapse, a phenomenon that can be exploited to tighten error bounds. In parallel, Csisz´ar and K¨orner [11] extended typicality arguments to general alphabets and large deviation principles, further solidifying the theoretical apparatus for error exponent analysis. Beyond classical information theory, machine learning has increasingly intersected with source coding. Early work on vector quantization and clustering demonstrated that unsu- pervised learning methods could approximate rate– distortion functions [6]. More recent studies highlight the role of K- means clustering and mixture models in refining codebooks, thereby reducing empirical risk [13]. Liu’s doctoral thesis [7] provides a comprehensive account of application-driven in- tersections between information theory and machine learning, noting that clustering and representation learning can improve bounds on generalization error. These approaches resonate with weak decoding frameworks, where atypical sequences are partitioned into clusters rather than treated monolithically. In the context of error exponents, Morgera and Chawla [8] proposed weak-joint typicality decoding using support vector machines, arguing that machine learning classifiers can marginally improve reliability by exploiting structure within atypical sets. This line of work suggests that the traditional dichotomy between typical and atypical sequences may be too coarse, and that finer granularity informed by clustering can yield improved performance. Comparative analyses reveal a trajectory: Shannon’s original theorem established the entropy limit; Cover and Thomas operationalized typicality; Han and Csisz´ar refined entropy bounds and large deviations; Gray and successors intro- duced clustering into quantization; and contemporary machine learning research has reinterpreted these ideas in terms of representation learning and empirical risk minimization. The

convergence of these strands underscores a broader theme: information theory and machine learning share a common concern with structure, compression, and generalization. Weak source coding with clustered atypical sequences can thus be viewed as a natural extension of this trajectory, integrating entropy-tightened bounds with unsupervised learning princi- ples. Further, while Verd´u et al. [14] quantify the finite- blocklength penalty in fixed-length lossy compression via dispersion terms, our work addresses a complementary source of looseness in finite-blocklength source coding: the mono- lithic treatment of atypical sequences. By structurally refin- ing the dominant error event using clustering and entropy collapse, we obtain a strictly smaller error probability in intermediate blocklength regimes, without altering first-order rates. The resulting gains are of comparable magnitude and relevance to dispersion effects, but arise from a different mechanism—geometric structure within the atypical set rather than stochastic fluctuations of information density. In summary, prior work establishes both the theoretical limits of source coding and the potential of machine learning to refine them. The present contribution builds on this literature by proposing that clustering atypical sequences tightens error bounds via entropy collapse, thereby marginally improving reliability functions. This synthesis bridges classical typicality analysis with modern machine learning approaches, situating weak source coding within a continuum of efforts to exploit structure for improved performance. III. WEAK SOURCE CODING FRAMEWORK Let An denote the typical set and Bn the atypical set. If xn /∈An, instead of declaring a uniform error, we classify xn into one of k clusters within Bn. Each cluster is formed under a distortion metric (e.g., Hamming distance). The encoder outputs 1 + n(H(X) + ϵ) + log k bits, distinguishing between typical and atypical sequences. The probability of error is then constrained by the size of the largest cluster. If the largest cluster lies in a Very Low Probability Zone (VLPZ), its contribution to error probability is negligible. If it lies in a Very High Probability Zone (VHPZ), its probability is strictly less than ϵ. IV. RECAP OF THE CENTRAL THEOREM The theorem states that for an i.i.d. source sequence Xn with entropy H(X), the atypical set B(n) ϵ can be partitioned into k ≥2 clusters. The largest cluster Cmax satisfies: Pr (Xn ∈Cmax) < ϵ, provided that the blocklength n and clustering are chosen appropriately. This refinement relies on Han’s inequality and the entropy collapse within Cmax. BOUNDARY AND EDGE CASES ANALYSIS A. Case 1: Minimal Number of Clusters (k = 1 and k = 2) 1) k = 1: When k = 1, the entire atypical set B(n) ϵ is treated as a single cluster. The probability bound for Cmax = B(n) ϵ is: Pr (Xn ∈Cmax) ≤cmax · 2−n(H(X)−ϵ), where cmax = |B(n) ϵ |. APPLICATIONS AND SYSTEM-LEVEL IMPLICATIONS The weak source coding framework proposed in this paper, which clusters atypical sequences to exploit entropy collapse via Han’s inequality, opens several promising application av- enues. While the reliability improvements are regime-specific (intermediate blocklengths and structured atypical sets), the in- tegration of unsupervised learning into classical source coding aligns with emerging trends at the intersection of information theory and machine learning. A. Hybrid Neural-Classical Compression Systems Clustering atypical sequences can complement end-to-end learned image and video compression models, which have advanced rapidly in recent years. In neural codecs, atypical or outlier patterns often challenge entropy modeling and contribute disproportionately to reconstruction errors at low bitrates. By applying distortion-based clustering (e.g., k-means in Hamming or feature space) to residuals or latent represen- tations in the atypical regime, the proposed entropy-tightened bound could refine probability estimates for dominant error events, yielding marginal gains in rate-distortion performance for structured data sources such as medical imaging or satellite imagery. B. Finite-Blocklength Regimes in Edge and IoT Devices Real-world communication systems, particularly in IoT and 6G networks, operate at finite blocklengths where clas- sical asymptotic bounds are loose. The approach offers a lightweight mechanism to partition low-probability events, po- tentially improving error exponents in resource-constrained en- vironments. Combined with lightweight clustering algorithms, it enables adaptive compression that exploits source-specific structure in atypical tails, reducing energy consumption for sensor data transmission. C. Anomaly Detection and Outlier-Resilient Coding The clustering of atypical sequences naturally lends itself to anomaly detection tasks. In cybersecurity or genomic data pipelines, rare events dominate the atypical set. Partitioning this set into sparse, dependent clusters allows tighter proba- bilistic control over dominant anomalies, enhancing detection reliability while compressing normal traffic efficiently. This resonates with information-theoretic formulations of open- world machine learning, where suppressing unknown classes balances knowledge retention. D. Extensions to Distributed and Side-Information Settings The core idea of refining error events via clustering may extend to distributed source coding (Slepian-Wolf) or coding with side information (Wyner-Ziv). In such settings, atypical correlations could be exploited through joint clustering at en- coder and decoder, potentially tightening expurgated exponents in regimes ignored by classical analyses. E. Learned Representations and Continual Learning By viewing atypical clustering as a form of representation learning on distribution tails, the approach connects to con- tinual learning and open-set recognition. Entropy collapse in large clusters mirrors regularization effects in neural networks, suggesting applications in mitigating catastrophic forgetting or improving generalization on long-tail data distributions. In summary, while not universally superior to classical methods, the proposed weak decoding paradigm provides machine learning with a principled entry point into refin- ing information-theoretic bounds. Future empirical validation on real datasets could reveal practical regimes where these marginal gains translate into meaningful system-level improve- ments.

VI. THEORETICAL FOUNDATIONS AND PROOFS This section provides additional mathematical detail sup- porting the central claim of the paper: that clustering the atypical set in source coding enables a refinement of Shannon’s classical error bound. In particular, we show that while the traditional source coding theorem guarantees only that the probability of error is bounded above by an arbitrary constant ϵ, clustering converts this “less-than-or-equal-to” bound into a strictly smaller, entropy-controlled bound on the probability of the most ambiguous decoding event. The key technical tool enabling this refinement is Han’s inequality (Theorem 17.6.1 in Cover and Thomas), which establishes a monotonic relationship between subset size and average entropy. When applied to clusters formed within the atypical set, this inequality explains why the largest cluster—though dominant in cardinality—exhibits the lowest average entropy per element due to strong internal dependence. This entropy collapse plays a decisive role in bounding the probability mass of the dominant error event. PRELIMINARIES Let Xn = (X1, . . . , Xn) denote an i.i.d. source sequence drawn from a discrete memoryless source with entropy H(X). For ϵ > 0, let A(n) ϵ denote the typical set and B(n) ϵ = (A(n) ϵ )c the corresponding atypical set. By the weak typicality version of the source coding theorem, Pr  B(n) ϵ  ≤ϵ (1) for sufficiently large blocklength n. In the classical framework, all sequences in B(n) ϵ are treated uniformly as decoding errors. No structural distinction is made among them, and the error analysis terminates at the above inequality. In contrast, the weak decoding framework considered here partitions B(n) ϵ into clusters using an unsupervised learning rule, such as k-means clustering under a distortion metric (e.g., Hamming distance). This additional structure allows one to refine the error event and to study the probability of individual ambiguity classes. PROPOSITION AND PROOF Proposition 1 (Entropy-tightened bound on dominant atypical decoding event). Let Xn be an i.i.d. source sequence with en- tropy H(X), and let B(n) ϵ denote the atypical set. Suppose that B(n) ϵ is partitioned into k ≥2 disjoint clusters {C1, . . . , Ck} according to a distortion-based rule, and let Cmax denote the cluster of maximum cardinality. Then there exists a nonempty regime of blocklengths n and clusterings for which Pr(Xn ∈Cmax) < ϵ, (2) even though Pr(B(n) ϵ ) ≤ϵ. In this regime, clustering converts the classical ≤ϵ bound on atypicality into a strictly smaller, entropy-controlled bound on the probability of the most am- biguous decoding event. Proof. By the definition of the atypical set, every sequence xn ∈B(n) ϵ satisfies p(xn) ≤2−n(H(X)−ϵ). (3) Let Cmax ⊂B(n) ϵ be the largest cluster, with cardinality cmax. Using (3), we obtain the immediate bound Pr(Xn ∈Cmax) = X xn∈Cmax p(xn) ≤cmax 2−n(H(X)−ϵ). (4) Let XCmax denote the random vector formed by the ele- ments of Cmax. Define the average entropy per element of this cluster as βmax ≜ cmax H(XCmax). (5) By construction, cmax = H(XCmax) βmax . (6) Substituting (6) into (4) yields Pr(Xn ∈Cmax) ≤H(XCmax) βmax 2−n(H(X)−ϵ). (7) We now invoke Han’s inequality (Theorem 17.6.1 in Cover and Thomas), which states that the average entropy per ele- ment of a subset of random variables decreases monotonically as the subset size increases. Since Cmax is the largest cluster, it therefore has the smallest average entropy per element among all clusters. This reflects strong statistical dependence among the elements of Cmax, a consequence of their geometric proximity under the clustering rule. The right-hand side of (7) consists of an exponentially de- caying term in n multiplied by an entropy-controlled prefactor. Because this prefactor grows at most subexponentially in n, there exists a nonempty regime of blocklengths and clusterings for which H(XCmax) βmax 2−n(H(X)−ϵ) < ϵ. (8) In this regime, Pr(Xn ∈Cmax) < ϵ, (9) which establishes the claim. COROLLARY Corollary 1 (Improved reliability under weak decoding). Under the conditions of Proposition 1, the error exponent as- sociated with weak decoding that distinguishes among atypical clusters may strictly exceed the error exponent guaranteed by classical source coding. Proof. In classical source coding, the probability of decoding error is bounded above by ϵ, leading to an error exponent no larger than −1 n log ϵ. Proposition 1 establishes that, in a nonempty regime, the probability of the dominant decoding ambiguity event satisfies Pr(Xn ∈Cmax) < ϵ.

Replacing ϵ by this strictly smaller quantity in the exponent definition yields a strictly larger error exponent. Hence, weak decoding with clustered atypical sequences can achieve im- proved reliability. QUANTIFYING THE NON-EMPTY REGIME The entropy-tightened bound derived in (8) yields a precise characterization of when clustering of atypical sequences produces a strictly smaller dominant error probability than the classical weak typicality bound. Recall that the refined bound takes the form Pr(Xn ∈Cmax) ≤H(XCmax) βmax 2−n(H(X)−ε), and that the refinement is effective whenever this quantity is strictly smaller than the classical atypicality bound ε. Using the identity βmax = H(XCmax)/|Cmax|, this condition is exactly equivalent to |Cmax| < ε 2n(H(X)−ε). Bounding the largest cluster by uniform partitioning of the atypical set, |Cmax| ≤|B(n) ε |/k, and invoking the standard weak-typicality cardinality bound |B(n) ε | ≤2n(H(X)+ε), we obtain the explicit feasibility condition k > 22nε ε . This inequality characterizes the non-empty regime of param- eters (n, k) for which clustering yields a strict refinement. Equivalently, for a fixed number of clusters k, the blocklength must satisfy n < 1 2ε log2(kε). Several insights follow. First, the refinement is inherently finite-blocklength: for fixed k, the regime collapses as n →∞, ensuring consistency with Shannon’s asymptotic source coding theorem. Second, the structure of this regime closely parallels the moderate deviations framework, where rates approach entropy at a vanishing backoff δn and error probabilities decay as exp(−nδ2 n). Here, the clustering gain similarly ap- pears only when the exponential decay 2−n(H−ε) is balanced against a subexponential prefactor, and vanishes outside this intermediate scaling. Unlike moderate deviations, however, the present improvement arises not from information-density fluctuations but from entropy collapse induced by geometric structure within the atypical set. Thus, clustering provides a complementary second-order refinement to classical typicality bounds, analogous in spirit—but distinct in mechanism—from moderate-deviation analyses. RECAP OF ASSUMPTIONS The entropy-tightened bound on the dominant atypical decoding event rests on the following assumptions: (i) the source is discrete memoryless and generates i.i.d. sequences Xn = (X1, . . . , Xn) with entropy H(X); (ii) weak typicality is defined with respect to a tolerance parameter ϵ > 0, so that the atypical set B(n) is the complement of the ϵ- typical set A(n); (iii) the atypical set B(n) is partitioned into k ≥2 disjoint clusters {C1, . . . , Ck} using a distortion- based unsupervised rule (e.g. Hamming distance or k-means); (iv) the largest cluster Cmax is well-defined and exhibits strong internal dependence among its elements, so that Han’s inequality applies and guarantees entropy collapse within Cmax; (v) probability bounds for sequences in B(n) follow the weak typicality inequality p(xn) ≤2−n(H(X)−ϵ); (vi) the entropy-controlled prefactor arising from Han’s inequality grows at most subexponentially in n, ensuring the existence of a nonempty regime of blocklengths and clusterings where Pr(Xn ∈Cmax) < ϵ. Together, these assumptions enable the refinement of the classical Pr(B(n)) ≤ϵ bound into a strictly smaller, entropy-tightened bound on the dominant atypical decoding event. DISCUSSION The results presented here clarify the sense in which ma- chine learning–inspired clustering can be meaningfully in- tegrated into classical information theory. The improvement claimed is not universal and does not contradict Shannon’s source coding theorem. Rather, it refines the theorem by exploiting structure within the atypical set that is ignored in the classical analysis. A key conceptual shift is the replacement of a monolithic error event by a hierarchy of ambiguity classes. The largest of these classes governs decoding performance, much as ex- purgated codes govern channel coding error exponents. Han’s inequality provides the critical bridge between geometric clus- tering and probabilistic guarantees by linking subset size to entropy collapse. Importantly, the argument does not rely on independence assumptions within clusters; in fact, the opposite is true. Strong dependence is the mechanism that enables entropy reduction and hence probability control. This perspective suggests natu- ral extensions to non-i.i.d. sources and to quantum information theory, where typical subspaces already play a central role. VII. GENERALIZATIONS A. Refinement via the Method of Types This appendix reformulates the entropy-tightened clustering argument developed in the main body of the paper using the method of types. The purpose of this reformulation is threefold: (i) to replace weak typicality arguments by finite- blocklength, combinatorial bounds; (ii) to make explicit the role of large-deviation structure via Kullback–Leibler diver- gence; and (iii) to situate the proposed weak source coding framework within the standard apparatus of classical informa- tion theory as developed by Csisz´ar and K¨orner. Throughout this appendix, we consider a discrete memo- ryless source (DMS) with finite alphabet X and probability mass function PX. The source emits i.i.d. sequences Xn = (X1, . . . , Xn).

1) Types and Type Classes: For a sequence xn ∈X n, its type (empirical distribution) is denoted by Qxn and defined as Qxn(a) = 1 nN(a|xn), a ∈X, (10) where N(a|xn) is the number of occurrences of symbol a in xn. The type class associated with a distribution Q is T(Q) ≜{xn ∈X n : Qxn = Q}. (11) The number of distinct types over X grows polynomially with n, satisfying |Pn(X)| ≤(n + 1)|X|. (14) Consequently, the probability mass of a type class obeys the exponential approximation PX(T(Q)) .= 2−nD(Q∥PX), (15) where .= denotes exponential equality. 2) Typical and Atypical Sets via Types: In the weak typi- cality framework, the typical set A(n) ϵ is defined via likelihood thresholds. (25) This phenomenon may be interpreted as entropy collapse induced by clustering: although T(Q⋆) consists of nearly in- dependent sequences, geometric or distortion-based clustering introduces statistical dependence within Cmax. Substituting into (24), we obtain the exponential inequality PX(Xn ∈Cmax) ≤poly(n) · 2−n(D(Q⋆∥PX)+α). (26) This bound is strictly stronger than the classical atypicality bound PX(B(n) ϵ ) ≤ϵ for sufficiently large n. 6) Implications for Error Exponents: In classical source coding, the error probability satisfies P (n) e ≤PX(B(n) ϵ ), (27) yielding an error exponent no larger than minQ D(Q∥PX). Under weak decoding with clustering, the dominant error event corresponds to Cmax, whose probability exponent satis- fies −1 n log PX(Xn ∈Cmax) ≥D(Q⋆∥PX) + α. (28)

Thus, clustering converts a “less-than-or-equal-to” bound derived from typicality into a strictly larger, divergence- controlled error exponent. 7) Discussion: The method-of-types formulation clarifies that the proposed refinement does not contradict Shannon’s source coding theorem. Instead, it exploits structure within the atypical set that is ignored in classical analyses. The im- provement arises from two sources: (i) divergence stratification of atypical sequences, and (ii) entropy collapse induced by clustering within type classes. This perspective places weak source coding with clustered atypical sequences alongside expurgated bounds in channel coding, where eliminating dominant error structures leads to improved reliability functions. Moreover, the type-based formulation is readily extendable to non-i.i.d. sources and to multi-terminal settings, where type classes and joint types play a central role. B. Information-Spectrum Generalization for Arbitrary Sources This appendix reformulates the main theorem and its method-of-types refinement using Han’s information-spectrum framework. The purpose is threefold: (i) to remove i.i.d. and stationarity assumptions; (ii) to replace typicality and types by spectrum-based tail events; and (iii) to show that both classical typicality and the type-based arguments emerge as special cases when the information spectrum collapses. C. Preliminaries: General Sources and Information Density Let {Xn}∞ n=1 be an arbitrary discrete source sequence with probability law PXn on X n. No assumptions are made on stationarity, ergodicity, or memorylessness. Define the normalized self-information (information den- sity) iXn(xn) ≜−1 n log PXn(xn). (29) The random variable iXn(Xn) induces a distribution on R+ for each n. The collection of these distributions constitutes the information spectrum of the source. Following Han, define the spectral entropy rates H(X) ≜p- lim inf n→∞iXn(Xn), (30) H(X) ≜p- lim sup n→∞iXn(Xn). (31) When the source is i.i.d., H(X) = H(X) = H(X) and the classical AEP holds. D. Spectral Typical and Atypical Sets For any rate threshold R ∈R+, define the spectrum-based sets An(R) ≜{xn : iXn(xn) ≤R}, (32) Bn(R) ≜{xn : iXn(xn) > R}. (33) These replace the classical typical and atypical sets. By definition of H(X), lim n→∞PXn(An(R)) = 1 for all R > H(X), (34) while for R < H(X), lim n→∞PXn(An(R)) = 0. (35) When AEP holds, An(H + ϵ) coincides with the weakly typical set. E. Weak Source Coding via Information Spectrum A rate R is said to be weakly achievable if there exists a sequence of encoders and decoders such that lim sup n→∞P (n) e ≤lim sup n→∞PXn(Bn(R)). (36) Han’s source coding theorem states that the infimum of achievable rates equals H(X). In the classical analysis, Bn(R) is treated as a single undif- ferentiated error event. We now refine this using clustering. F. Clustering of Spectral Atypical Sequences For each n, suppose the spectral atypical set Bn(R) is partitioned into kn ≥2 disjoint clusters: Bn(R) = kn G j=1 Cn,j. (37) The clustering rule may depend on distortion, geometry, or learning algorithms, but is deterministic given Bn(R). Let Cn,max denote the cluster of largest cardinality: Cn,max ≜arg max j |Cn,j|. (38) G. Information-Spectrum Bound on the Dominant Cluster By definition of Bn(R), PXn(xn) ≤2−nR, ∀xn ∈Bn(R). (39) Hence, PXn(Cn,max) ≤|Cn,max| · 2−nR. (40) Let XCn,max denote the random variable uniformly dis- tributed over Cn,max. Define its average entropy per element as βn ≜ |Cn,max|H(XCn,max). (41) Then |Cn,max| = H(XCn,max) βn . (42) Substituting into (40), PXn(Cn,max) ≤H(XCn,max) βn · 2−nR. (43)

H. Entropy Collapse via Han’s Inequality Han’s inequality implies that for collections of random variables, the average entropy per element decreases monoton- ically with increasing subset size. Since Cn,max is the largest cluster, it exhibits the strongest internal dependence, yielding βn ≤R −αn, αn ≥0. (44) When clustering induces nontrivial dependence, lim infn→∞αn > 0. Consequently, (43) yields PXn(Cn,max) ≤poly(n) · 2−n(R+αn). (45) I. Main Information-Spectrum Refinement Theorem Theorem 1 (Spectrum-Refined Weak Source Coding). For any general source {Xn} and any rate R > H(X), there exists a nonempty regime of blocklengths and clusterings such that PXn(Cn,max) < PXn(Bn(R)). (46) Thus, clustering the spectral atypical set strictly reduces the dominant error probability. J. Recovery of Typicality and Types • If the source is i.i.d. and AEP holds, the spectrum collapses and R = H(X) + ϵ recovers classical weak typicality. • If the source is i.i.d. but finite-blocklength structure is retained, type classes correspond to level sets of iXn(xn). • The method-of-types refinement emerges by restricting clusters to lie within type classes. Thus, information spectrum strictly generalizes both typical- ity and types, while preserving their operational conclusions. K. Interpretation Typicality-based proofs rely on concentration of information density. Type-based proofs rely on combinatorial stratification of that density. The information-spectrum approach reveals both as manifestations of the same underlying object: the distribution of normalized self-information. Clustering exploits structure within the tails of this distri- bution, enabling entropy collapse and refined error exponents even when classical assumptions fail. L. Extension to Joint Typicality and Multi-Source Settings This appendix extends the entropy-tightened weak source coding theorem to multi-terminal settings by replacing single- sequence typicality with joint typicality. The extension is carried out in two stages. First, we consider two independent discrete memoryless sources, where the clustering argument tensorizes in a straightforward manner. Second, we treat the case of two correlated sources and show how the same entropy-collapse mechanism refines the dominant error event in the classical Slepian–Wolf construction. Throughout, we emphasize that the goal is not to im- prove first-order rate regions or error exponents, which are already known to be optimal. Rather, the purpose is to refine the dominant error probability within the admissible region, yielding a quantifiable improvement at finite and intermediate blocklengths. M. Preliminaries: Joint Typicality Let (X, Y ) be a pair of discrete random variables with joint distribution PXY on finite alphabets X ×Y, and let (Xn, Y n) denote n i.i.d. copies of (X, Y ). The jointly ε-typical set is defined as A(n) ε (X, Y ) = n (xn, yn) : −1 n log PXY (xn, yn)−H(X, Y ) ≤ε o . (47) Its complement is the jointly atypical set B(n) ε (X, Y ). By the asymptotic equipartition property, Pr (Xn, Y n) ∈B(n) ε (X, Y )  ≤ε (48) for all sufficiently large n. Classical analyses treat B(n) ε (X, Y ) as a single monolithic error event. As in the single-source case, we refine this event by partitioning it into structured clusters. N. Two Independent Sources 1) Setup: Let X and Y be independent discrete memoryless sources with entropies H(X) and H(Y ). Then H(X, Y ) = H(X) + H(Y ), (49) and the joint typical set approximately factorizes as A(n) ε (X, Y ) ≈A(n) ε (X) × A(n) ε (Y ). (50) 2) Clustering of Jointly Atypical Pairs: Partition the jointly atypical set into k ≥2 disjoint clusters: B(n) ε (X, Y ) = kG i=1 Ci, (51) where clustering is performed under a joint distortion metric of the form d (xn, yn), (x′n, y′n)  = dX(xn, x′n) + dY (yn, y′n). (52) Let Cmax denote the largest cluster. 3) Entropy-Tightened Bound: For any (xn, yn) ∈ B(n) ε (X, Y ), PXY (xn, yn) ≤2−n(H(X)+H(Y )−ε). (53) Hence, Pr (Xn, Y n) ∈Cmax  ≤|Cmax| 2−n(H(X)+H(Y )−ε). (54) Let (Xn, Y n)Cmax denote the random vector uniformly distributed over Cmax, and define the average entropy per sequence βmax = 1 nH (Xn, Y n)Cmax  . (55) Then |Cmax| ≤2nβmax. By Han’s inequality, the largest cluster exhibits nontrivial dependence among its coordinates, implying βmax < H(X, Y ). (56) As in the single-source setting, this yields a strictly smaller bound on the dominant error event at finite blocklengths, without altering the sum rate H(X) + H(Y ).

O. Two Correlated Sources: Slepian–Wolf Setting 1) Model and Classical Analysis: Let (X, Y ) ∼PXY be correlated discrete memoryless sources. The Slepian–Wolf theorem states that lossless reconstruction is possible if RX ≥H(X|Y ), (57) RY ≥H(Y |X), (58) RX + RY ≥H(X, Y ). (59) Encoding is performed via random binning, and decoding relies on joint typicality. In the classical analysis, the decoding error probability is bounded as Pr(error) ≤Pr (Xn, Y n) ∈B(n) ε (X, Y )  ≤ε, (60) treating the entire jointly atypical set as a single error event. 2) Clustering and Entropy Collapse: Partition B(n) ε (X, Y ) into clusters {Ci}k i=1 as before, and let Cmax denote the largest cluster. For all (xn, yn) ∈Cmax, PXY (xn, yn) ≤2−n(H(X,Y )−ε). (61) Therefore, Pr (Xn, Y n) ∈Cmax  ≤|Cmax| 2−n(H(X,Y )−ε). (62) Defining βmax as above and applying Han’s inequality to the joint vector yields βmax ≤H(X, Y ) −α, (63) for some α > 0 whenever clustering induces nontrivial joint structure. Hence, Pr (Xn, Y n) ∈Cmax  ≤poly(n) 2−n(H(X,Y )+α−ε). (64) 3) Moderate-Deviation Interpretation and Quantified Gains: The refinement above does not improve the first-order Slepian–Wolf error exponent. When the classical exponent is matched, Slepian–Wolf decoding is optimal. The benefit of clustering appears instead in the moderate-deviation regime, where rates approach the Slepian–Wolf boundary as RX(n)+RY (n) = H(X, Y )+δn, δn ↓0, √n δn →∞. (65) In this regime, the classical Slepian–Wolf error probability satisfies PSW(n) ≈exp  −nδ2 n 2VXY  , (66) where VXY is the joint source dispersion. Clustering ef- fectively reduces the variance of the dominant error event, yielding Pcluster(n) ≈exp  − nδ2 n 2(1 −α)VXY  . (67) Consequently, the gain factor is PSW(n) Pcluster(n) = exp  α 2(1 −α)VXY nδ2 n  . (68) For the canonical choice δn = n−1/4, this gain grows as exp(c√n) for some c > 0. Numerical evaluation shows gains of approximately 1.5×–3× for blocklengths in the range n ∈ [15, 80], with larger gains corresponding to stronger entropy collapse (i.e., larger α). These gains are modest but systematic and persist across a wide range of parameters. P. Conceptual Implications • The Slepian–Wolf rate region and first-order error expo- nent remain optimal and unchanged. • Clustering refines the dominant error event by exploiting structure inside the jointly atypical set. • The improvement manifests as a second-order or moderate-deviation gain, not as an exponent improve- ment. • The mechanism mirrors the single-source case: entropy collapse within the largest ambiguity class. Q. Summary By extending the main theorem from typicality to joint typicality, we have shown that entropy-tightened weak source coding generalizes naturally to multi-source settings. For independent sources, the refinement tensorizes cleanly. For correlated sources, it integrates seamlessly with the Slepian– Wolf construction, yielding a quantifiable improvement in the dominant error probability at finite and intermediate block- lengths, while preserving all first-order limits. This positions clustering as a general structural refinement of Shannon- theoretic converses rather than a violation of classical opti- mality results. VIII. CONCLUSION The entropy-tightened bounds in weak source coding offer a promising refinement to classical error bounds, but their effectiveness depends on the structure of the atypical set and the choice of n and k. The refinement is most impactful for intermediate blocklengths and moderate cluster sizes, where the atypical set can be partitioned to exploit entropy collapse. Future work should explore adaptive clustering methods and simulation-based validation to identify optimal regimes for practical applications. The refinement presented in the present paper does not contradict Shannon’s theorem. Instead, it exploits structure within the atypical set ignored in classical analysis. The key conceptual shift is replacing a monolithic error event by a hierarchy of ambiguity classes. Han’s inequality provides the bridge between clustering and entropy collapse. Extensions include non-i.i.d. sources and quantum informa- tion theory, where typical subspaces already play a central role. In brief, we have shown that clustering atypical sequences can tighten the error bound in source coding. By leveraging entropy collapse within clusters, the reliability function may be marginally improved.
