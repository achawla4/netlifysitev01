A Quantum Algorithm for MAXSAT

Chawla, Aman

Abstract

In this report, we use a Large Language Model (LLM) called Chat- GPT to create a new quantum algorithm for the satisability problem MAXSAT1. We then have the LLM generate a script that implements the algorithm and presents the results. Next we perform a quantum analysis and compute the measurement probability of the various outcomes of the algorithm. Part I Basic Formulation To design a unitary operation V using Kempe's quantum random walk approach, with the goal of nding the target state that represents the maximal value or a value closest to the maximal value of a weighted sum of m known clauses, we can leverage the structure of quantum walks on a Hilbert space associated with the n-qubit system. Problem Setup: The key components of the problem setup are as follows. Quantum State Space: The system has n qubits, leading to a computational basis of dimension 2n. Each basis state |x⟩corresponds to a specic assignment of 0 or 1 to the n variables. Clauses: There are m clauses, each contributing to a weighted sum based on the specic assignment of variables in | x⟩. The goal is to nd the state | x∗⟩ that either maximizes or is closest to maximizing this weighted sum. 1LLM and ML/AI use is becoming more prevalent in elds related to quantum physics [1]. 1

Quantum Walk: We will design V based on a quantum walk that eciently explores the computational basis, guiding the evolution towards the desired target state | x∗⟩. Next, we discuss our approach in detail. Weighted Sum Objective Function Dene an objective function f(x) that represents the weighted sum of the clauses for a given assignment x. The goal is to nd the state | x∗⟩where f(x∗) is maximal. Hilbert Space and Oracle Function Hilbert Space: The state space is C2n where each basis state | x⟩corresponds to a potential solution. Oracle Function Of: Dene an oracle unitary Of that marks the basis states based on the value of f(x) [2]. Specically, if the value of f(x) is larger than the value of f(x) in all previous steps, the state x is marked as red and previous marked red states are ipped to blue. For another example: Of | x⟩= −1f(x) | x⟩. This oracle ips the phase of the state if f(x) is above a certain threshold, thereby marking promising states. Quantum Random Walk on the Hypercube: Consider a quantum walk on the n-dimensional hypercube, where each vertex corresponds to a state |x⟩, and edges represent transitions between states that dier by one bit. Dene a step operator S that applies a quantum walk on this hypercube, transitioning between adjacent vertices (states) [3]. The step operator could be designed as: S = P x Pn i=1 | x L ei⟩⟨x |⊗| i⟩⟨i | where ei is the basis vector corresponding to ipping the i-th bit. Combining Walk with Oracle Of : The key idea is to combine the quantum walk operator S with the oracle Of. The evolution of the quantum state is then driven by the repeated application of these operations: W = OfS. This unitary W eectively "guides" the quantum walk by marking promising states (based on f(x)) and then spreading amplitude towards those states. Reection and Iterative Amplication: Reection about the Average: Introduce a reection operation R that reects the current state about the average state [4]. This is akin to Grover's 2

diusion operator: R = 2| φ0⟩⟨φ0| −1 where | φ0⟩is the uniform superposition state [5]. Iterative Application: The nal procedure involves iteratively applying the composite operator V = RW several times. This amplies the amplitude of the states that are marked by the oracle (i.e., states close to the maximum value of f(x). Measurement: After sucient iterations (the optimal number can be determined based on the problem size n), the nal state is measured. The probability of obtaining the state | x∗⟩that maximizes or is closest to maximizing f(x) should be signi- cantly amplied. Summary: 1. Initialize: Start with the uniform superposition of all basis states. | φ0⟩= 2n P2n−1 | x⟩. 2. Quantum Walk + Oracle: Apply the composite operator W = Of S to guide the quantum walk towards states with higher objective values f(x). 3. Amplitude Amplication: Use a reection operator R to amplify the probability amplitude of promising states. The overall unitary V = RW is applied iteratively. 4. Measurement: Measure the nal state, which will most likely collapse to the state | x∗⟩that maximizes f(x) or is close to the maximum. This approach leverages Kempe's quantum random walk technique combined with amplitude amplication to eciently nd the target state | x∗⟩in a high-dimensional search space. Part II Extended Oracle To implement the described coloring mechanism in a quantum context, you can design a quantum circuit that uses an oracle Of to compare the values of a function f(x) at dierent inputs and mark the states accordingly. Here's how you can conceptualize and implement this: 4

Quantum Oracle Of Denition The oracle Of is dened to compare the value of f(x) with the maximum value of f(x) seen so far. If f(x) is larger, the oracle marks the corresponding quantum state |x⟩as "red" by ipping a specic ancilla qubit, and if it is smaller, the state is not marked. Additionally, if a state is marked as red, previous red-marked states are ipped to blue. Steps to Implement the Coloring 1. Initialize the Quantum State: Start with a quantum register |x⟩ representing the inputs, an ancillary register |c⟩to store color states (where |0⟩ is uncolored, |1⟩is red, and |2⟩is blue), and a register |m⟩to track the maximum f(x) seen so far. |ψ⟩= |x⟩⊗|c⟩⊗|m⟩ (1) 2. Compute f(x): Use a quantum circuit to compute f(x) and store it in a temporary register |f⟩. |ψ⟩→|x⟩⊗|c⟩⊗|m⟩⊗|f(x)⟩ (2) 3. Compare f(x) with the Maximum Value: Apply a comparator quantum circuit to compare f(x) with the value stored in the |m⟩register. If f(x) is larger, set |m⟩to f(x), and ip the color qubit in |c⟩to mark the state as red (value 1). |ψ⟩→|x⟩⊗|1⟩⊗|f(x)⟩ if f(x) > m (Mark as red) (3) Otherwise, the state remains unmarked or as blue. 4. Unmark Previous Red States: To ip previously marked red states to blue (value 2), you need to iterate over the states. Implement a controlled operation that checks if a state was previously marked as red and ips it to blue if the current state is marked red. |ψ⟩→|x⟩⊗|2⟩⊗|f(x)⟩ (Flip previous red to blue) (4) 5. Reset Ancilla Registers: After marking the states, reset the ancilla registers |f⟩and |m⟩to their initial states, if necessary, to ensure they don't interfere with subsequent operations. Quantum Circuit Implementation The circuit implementing this coloring procedure consists of: 5

Function Evaluation: A subcircuit that evaluates f(x). Comparator: A comparator subcircuit that compares f(x) with the stored maximum value. Coloring: Controlled operations to mark states as red or ip them to blue. Reset Operations: If necessary, reset operations for ancilla registers. Conclusion This process leverages quantum parallelism to eciently mark and unmark quantum states based on the comparison of function values. The key operations are the quantum oracle Of, the comparator, and the controlled operations for ipping colors. This approach ensures that at each step, the state corresponding to the largest f(x) so far is marked as red, and all previous red-marked states are ipped to blue. The auxiliary qubit helps track the color state and can be manipulated based on the function evaluations during the oracle's execution.
