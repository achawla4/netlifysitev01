Bodhsanchar 1: Agent-Aided Maritime Communication System for Green Port Operations

Chawla, Aman

Abstract

This paper presents Bodhsanchar 1, an AI-enabled, agent-aided maritime communication framework designed for resilient green port operations. Addressing noise, interference, and extreme weather, the system adapts transmission power, modes, and feedback in real-time using hierarchical agents and reinforcement learning. A proposed low-cost prototype with JioFi-class devices demonstrates robust ship-to-shore links under adverse conditions. The solution enhances logistics efficiency, conserves energy, aligns with “Harit Sagar” sustain- ability goals, and offers scalable deployment from small vessels to large port networks. Selected Innovation Theme Smart Logistics & AI-Powered Maritime Operations. Description of the Problem-Solution Fit Maritime communications face severe challenges in dynamic ocean environments, including atmospheric interference, sea state variations, vessel motion, and extreme weather like cy- clones—conditions prevalent around ports like Visakhapatnam. These disruptions lead to unre- liable links, increased transmission retries, delayed vessel coordination, and higher operational risks, ultimately hindering efficient port logistics and safety. Our solution is an AI-enabled, agent-aided communication framework that adapts feedback schemes for noisy, time-varying channels. Building on network information theory—rooted in the author’s 2006 MIT thesis on Gaussian channel reliability [1] — this system uses hierarchical agents to monitor and optimize parameters in real-time. The primary agent adjusts transmission power and modes based on channel state, while specialized agents can be included to handle weather prediction, interference management, and sea state effects using reinforcement learning. For Phase 1 deployment, we adapt affordable JioFi-category dongles with custom software agents to create a prototype for testing adaptive transmissions. This ensures robust ship- to-shore and vessel-to-vessel links, reducing outages and enabling seamless data flow for port operations even in high sea states or storms. It facilitates real-time environmental monitoring (e.g., pollution tracking) and integration with renewables (e.g., reliable links for wind/solar-powered systems), minimizing fuel use through better scheduling and preventing delays that lead to idling. Scalability is inherent in the modular design: agents can be deployed across networks, from small dongle-based setups to large-scale port systems, with extensions to MIMO or quantum protocols.
