ABSTRACT

This note explores the problem of recovering the initial user prompt X0 from the final output YT of a multi-turn conversation with a large language model (LLM) such as GPT. We model the LLM as a stochastic forward channel and the user as a feedback channel, forming an interactive communication system. Using Robbins-Monro stochastic approximation in semantic embedding space, we develop a practical algorithm to invert this noisy feedback loop. A complete manual-mode GUI implementation in Python/Tkinter is provided, along with experimental results demonstrating semantic recovery quality.

1 Introduction

Large Language Models (LLMs) can be viewed through the lens of Shannon’s information theory as stochastic channels. In a typical chat session, the user provides an initial prompt X0, the model generates responses, and the user supplies feedback, creating a closed-loop interactive system. Over multiple turns, the original prompt signal X0 becomes diluted due to the model’s autoregressive generation, context maintenance, and user-driven topic drift. The central question addressed in this work is: Given only the final response YT (or a short snippet of it), can we recover a good approximation of the original hidden prompt X0? This is a stochastic inverse problem. Direct maximum-likelihood estimation is intractable due to the enormous state space and unknown user feedback policy. We therefore employ Robbins-Monro stochastic approximation, a classical method for finding roots of noisy regression functions, adapted here to operate in semantic embedding space.

2 Theoretical Framing

We model the conversation as:

X0 →Y1 →X1 →Y2 →· · · →XT−1 →YT

where Yt is generated by the LLM (forward channel) and Xt by the user (feedback channel). The observer sees only YT and wishes to estimate X0. The objective is to minimize the expected semantic reconstruction loss:

θ∗= arg min θ E h d(ϕ(YT ), ϕ( ˜YT (θ))) i

where ϕ(·) is a sentence embedding function (e.g., all-MiniLM-L6-v2) and d is cosine distance. Robbins-Monro updates take the form:

θ$k = θk−1 −γkH(θk−1, ξk)$

with step size γ$k = a$ b+k satisfying P γ$k = ∞and P γ2$ k < ∞. This procedure converges almost surely to the optimal embedding θ∗under standard conditions, from which a text prompt can be decoded via an auxiliary LLM call.

3 Practical Implementation

We implemented a fully manual, GUI-based system using Tkinter. The user interacts with any preferred LLM (ChatGPT, Claude, Grok, local model, etc.) by copying prompts and pasting responses. The core algorithm runs in a background thread while maintaining a responsive interface with overall scrolling. Key components include:

• Semantic embedding using Sentence-Transformers

• Monte-Carlo rollouts with manual GPT and simulated user turns

• Robbins-Monro updates in embedding space

• Evaluation panel for ground-truth comparison

• Experiment logging to prompt recovery experiments.log

The GUI features a left main area for recovery workflow and a right evaluation panel that computes semantic distance, cosine similarity, and recovery quality after the user provides the actual initial prompt.

5 Experimental Result

We tested the system on a real conversation with the following parameters:

• Iterations: 2

• Rollouts per iteration: 2

• Maximum turns per simulation: 2

Observed Final Output (snippet): Discussion comparing personal research trajectory to Claude Shannon in terms of output, impact, and likelihood of creating a new field. Recovered Prompt:

I’ve produced hundreds of research works already and I’m trying to build something foundational—how does my trajectory compare to Claude Shannon’s in terms of output, impact, and the likelihood of creating a new field?

Actual Initial Prompt:

how many works did Shannon produce?

Evaluation Metrics:

• Semantic Distance: 0.5532

• Cosine Similarity: 44.68%

• Recovery Quality: Moderate

This result is reasonable given the extremely low computational budget. With only 2 turns, the forward channel has limited opportunity for drift, yet the recovered prompt still captures the broader semantic theme (comparing research impact to Shannon) while expanding beyond the narrow factual question about publication count. The gap illustrates information-theoretic limits: mutual information I(X0; YT ) decays with conversation length due to redundancy and topic evolution in the feedback loop.

6 Discussion and Future Work

Treating LLMs as stochastic channels with feedback opens several promising directions:

1. Scaling laws for prompt recovery accuracy versus number of iterations/rollouts

2. Semantic vs. literal recovery objectives

3. Integration with watermarking and provenance techniques

4. Theoretical bounds on interactive channel capacity for prompt inversion

The current implementation demonstrates that Robbins-Monro stochastic approximation is a viable and practical method for approximate prompt reconstruction, especially when operating in embedding space. Future enhancements could include automatic response handling via API, variance reduction techniques, and hybrid MCMC-Robbins-Monro samplers.

7 Conclusion

We have shown that recovering the initial prompt from the final LLM output is possible using stochastic approximation methods. The provided GUI serves as both a research tool and a demonstration of the approach. Even with minimal iterations, the method recovers semantically coherent approximations, highlighting both the power and the inherent limits of information propagation through LLM feedback channels. This work bridges classical stochastic approximation theory with modern generative AI systems and offers a foundation for further study of prompt inversion, conversation telemetry, and interactive information theory.
